# Documentation

Current-state architecture and the forward-looking roadmap for
`eureka-platform-bootstrap`.

- `architecture/` — what the repository is responsible for today, how it is
  structured, how it operates, and the principles that shape it.
- `roadmap/` — how the repository should evolve without losing its core idea: a
  transparent, local-environment tool for FOLIO Eureka development and testing.

## Current-state architecture

- `architecture/README.md` — architecture overview and repository responsibilities
- `architecture/system-context.md` — the repository in its wider environment
- `architecture/runtime-containers.md` — the runtime assembled by this repository
- `architecture/repository-components.md` — repository file-structure view
- `architecture/key-flows.md` — the main operational flows
- `architecture/principles.md` — design principles, invariants, and guardrails
- `architecture/supported-workflows.md` — supported workflows vs helpers

## Roadmap

- `roadmap/README.md` — roadmap and the current direction

## How to read this set

1. Start with `architecture/README.md`.
2. Read `architecture/system-context.md` and `architecture/runtime-containers.md`.
3. Use `architecture/repository-components.md` and `architecture/key-flows.md` for
   the working model.
4. Finish with `roadmap/README.md` for where the repository is intended to go next.
